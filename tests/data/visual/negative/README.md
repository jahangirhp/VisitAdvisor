# Negative visual test images

50 added artworks from the Cleveland Museum of Art: 35 paintings and 15 sculptures. The three pre-existing images are preserved separately and are not included in this manifest.

Expected result for the added images: no match against the current Rijksmuseum reference collection. These are museum collection photos, not visitor-camera photos. The downloaded web-sized JPEGs are unchanged; full-resolution masters were not downloaded.

`manifest.json` preserves museum source metadata, credits, CC0 status, source/image URLs, dimensions, and SHA-256 checksums. Distinct museum artwork IDs and image hashes were checked; reference-title matches and byte-identical original images were excluded. No recognition accuracy evaluation has been run.
